# Continuous association

Claim: Response increases with exposure in this synthetic dataset.

The workflow copies and hashes the raw comma-separated-value input, embeds the exact plotted table and statistical specification, verifies the visible carrier, reruns the trusted producer into a separate figure, and unpacks the recoverable evidence.
