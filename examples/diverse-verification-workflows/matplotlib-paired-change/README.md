# Paired change

Claim: Paired responses are higher after the intervention in this synthetic dataset.

Matplotlib draws one paired slope plot. A Wilcoxon signed-rank test is calculated by the producer and independently recalculated by ReproFig.

The workflow copies and hashes the raw comma-separated-value input, embeds the exact plotted table and statistical specification, verifies the visible carrier, reruns the trusted producer into a separate figure, and unpacks the recoverable evidence.

Open `presentation/index.html` for the presentation view. The data are synthetic and are not evidence for a real scientific conclusion.
